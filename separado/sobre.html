Sobre o projeto

O Turismo Consciente foi criado como atividade acadêmica para estudar turismo, sustentabilidade e responsabilidade social.

Missão

Incentivar informações simples sobre viagens responsáveis.

Visão

Mostrar que planejamento e respeito podem fazer parte de qualquer viagem.

Valores

Respeito, responsabilidade, acessibilidade, preservação e valorização local.

Como usar este site

Conheça

Explore os projetos, a galeria e os conteúdos sobre turismo responsável.

Planeje

Use as dicas e os roteiros ilustrativos como ponto de partida para sua pesquisa.

Compartilhe

Converse sobre preservação, inclusão e respeito à cultura local.

Sobre a atividade

Este projeto aplica HTML para organizar o conteúdo, CSS para a apresentação e JavaScript para validar o formulário. Os roteiros, indicadores e contatos são demonstrativos e não representam serviços de uma agência real.
