# Turismo Consciente

Projeto acadêmico de Front-End para ADS, 2º semestre.

## Como abrir

Abra index.html em um navegador. Preserve as pastas css e js junto das páginas.
Imagens, vídeo, áudio e mapa externos precisam de conexão com a internet.

## Formulário

O formulário valida os campos no navegador e simula o envio. Não existe servidor, envio de mensagem ou armazenamento de dados.

## Arquivos de texto

A pasta Codigos_TXT inclui as 10 páginas HTML, o CSS e o JavaScript, além da documentação, com extensão adicional .txt, UTF-8 e quebras de linha CRLF (Windows).
Para reconstruir o site a partir dos textos, remova apenas a extensão final .txt e preserve as subpastas.

## Pendências acadêmicas

Preencha os nomes da equipe no escopo. Os preços e a disponibilidade de domínios continuam pendentes de consulta. Confira as evidências de testes antes da entrega.
